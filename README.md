# Практика 1 · Веб-страница портфолио-резюме

Одностраничный сайт-портфолио на HTML, CSS и JavaScript.

## Использование AI-помощника

**Инструмент:** DeepSeek — помогал писать код, объяснял, как работают стили и скрипты, искал ошибки в подключении файлов.

**Задача:** создать одностраничный сайт-портфолио с тёмной эстетикой, Mobile First, секциями опыта, образования, навыков и проектов, с JavaScript-функционалом.

**Один существенный запрос:**
> «Роль: Ты — профессиональный frontend-разработчик и UI/UX дизайнер, специализирующийся на мрачной, минималистичной эстетике. Задача: Создай одностраничный сайт-визитку для персонажа аниме "Тетрадь смерти" — Ягами Лайта. Стек: Чистый HTML, CSS и JavaScript в одном файле. Шрифт: Yanone Kaffeesatz. Цветовая гамма: тёмные тона, акценты — киноварно-красный. Mobile First. Структура: хедер, hero с печатной машинкой, обо мне, миссия, проекты, контакты.»

**Результат проверки:**
AI сгенерировал полный HTML-файл со встроенными CSS и JavaScript. Проверила: структура секций совпала с заданием, шрифт и цвета подключились, печатная машинка работает, модалка по клику на логотип открывается. Дальше попросила разделить код на три файла — `index.html`, `style.css`, `script.js`, — чтобы было удобнее редактировать.

**Что я правила сама:**
- Указывала путь к фото в папке `images/`.
- Просила заменить квадрат с инициалами на фото в разделе «Обо мне».
- Просила добавить модальные окна с красными нитями в разделе «Проекты».

## JavaScript-функционал

- Эффект печатной машинки
- Плавный скролл по якорям
- Активная навигация при скролле
- Анимация появления секций
- Анимированные прогресс-бары навыков
- Модальные окна проектов
- Модалка по клику на логотип
- Валидация формы обратной связи
- Мобильное бургер-меню

## Mobile First

Стили написаны сначала под мобильные, затем расширены через `@media (min-width: 768px)` и `(min-width: 1024px)`.

## Время выполнения

~2 часа.
